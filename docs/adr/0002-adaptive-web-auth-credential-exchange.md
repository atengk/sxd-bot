# 0002 自适应 3 步 Web 鉴权凭据换取机制

神仙道官方运营区服的 TCP 网关地址、服务端口与登录校验令牌（Session Hash）高度动态化且受防重放时间戳保护，若在配置文件中硬编码固定 IP 与静态凭据，会导致区服合服、网关漂移或令牌过期时频繁握手失败；本项目决定设计自适应 3 步 Web 认证链，通过官方 Web 认证接口模拟登录，动态嗅探并解析出目标区服最新的入口 HTML，从中提取动态 Gateway 域名、端口及即时 Session Hash 凭据；这使得机器人摆脱对人工频繁抓包配置的依赖，实现全自动无人值守刷新。

## Status

accepted

## Considered Options

- **选项 1：3 步自适应 Web 认证链动态提取（采纳）**：用户名密码通过 Web 接口自动换取登录票据与目标区服动态网关，支持凭据过期自动无感重刷。
- **选项 2：静态配置文件硬编码网关 IP 与固定 Token**：每次运行必须手动抓包填写 Token，Token 有效期通常仅数小时，无法实现 24 小时无人值守。
- **选项 3：独立本地 Proxy 拦截官方微端抓包获取**：需要用户手动启动官方客户端配合抓包工具，破坏了全自动命令行与定时流水线的闭环。

## Consequences

- 彻底实现自动化闭环，支持 `--daemon` 常驻模式在长效运行中的自动重新鉴权；
- 网络模块增加了轻量 HTTP 依赖（如 `requests`），需妥善处理网络波动与 Web 端验证码/反爬策略。
