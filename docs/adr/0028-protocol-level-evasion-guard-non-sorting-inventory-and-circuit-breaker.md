# 28. 协议级顶号避让守卫、背包免排自理与日常流水线熔断急停决策

## 状态
已接受 (Accepted) - 2026-10-17

## 背景与问题陈述
在对大号真实运行日志排查时，发现大号在执行日常流水线期间突然掉线并触发防互踢避让，导致长连接关闭且账号陷入离线：
1. **TCP EOF 泛化误判为微端登录**：此前系统在底层连接断开（EOF/Reset）时，一律无差别判定为“微端登录让位（EOF断开）”，直接关停长连接托管并设定 3600 秒避让冷却，导致因网络抖动或异常发包引起的连接关闭直接杀死了托管机制。
2. **`ItemClassifyPackReq` 协议动作号与载荷错误导致网关强杀**：`ItemClassifyPackReq` 误配置为 `Mod 2, Act 52`（实际为获取角色装备 `get_player_role_equip_list`，需 4 字节入参），且载荷为空（0 字节）。神仙道官方网关收到长度不足的非法协议帧后，直接在底层掐断 TCP 套接字通道（返回 EOF），进而诱发了上述伪避让连锁反应。
3. **日常流水线与避让状态脱节**：托管长连接因上述原因断开并触发避让后，已启动的日常任务流水线在后台依然使用独立临时连接继续向网关发包，既未让位，又在完成 33 项日常后随临时连接释放将账号遗留在离线状态。

## 决策内容

### 1. 玩家自登零容忍防互踢避让 (Human-First Zero-Tolerance Evade)
- **神仙道网关单点鉴权踢线机制**：
  - 神仙道区服网关采用“后登踢前登”的单点登录规则。当玩家在官方微端或网页端登录成功时，服务端不会向前一个连接发送任何协议预警通知包，而是直接发送 TCP FIN/RST 强行切断旧套接字通道（客户端表现为 EOF）；
  - 此前误将 EOF 视作普通网络断线并执行 7.5 秒自动重连，导致机器人反复重新登录并将正在游玩的玩家强制顶下线（形成互踢死循环）；
- **建立态 EOF 严格判定为玩家顶号并立即避让**：
  - 在底层发包已彻底消除非法畸形包（如背包伪整理包）的前提下，正常自动化长连接绝不会因发包错误被服务端强关；
  - 因此，已成功登录握手并处于活跃维持态的长连接，一旦被服务端主动切断 (EOF)，**一律判定为玩家在微端/官方端自登**；
  - 协程必须立即调用 `trigger_evade("微端/网页端自登让位 (EOF断开)")`，关停长连接托管、强杀底层套接字并退出守护循环，确保玩家在微端拥有绝对最高操作特权，彻底消除抢线互踢；
  - 玩家游戏结束后，可随时在 Web 控制台点击【打完了·恢复托管】或【一键全员恢复】一秒唤醒托管。

### 2. 背包自理剔除冗余伪整理指令 (Non-sorting Inventory Pipeline)
- 神仙道官方并没有无参的一键整理协议（官方整理需要客户端在本地完成全部格子的排序算子后整体回传列表）。辅助机器人的核心诉求是“开箱、吃药、存仓、腾空格”，对视觉网格排序无依赖；
- 在日常巡检和清理流水线中彻底移除 `classify_pack` 发包动作，仅保留安全开箱、吃体力丹/经验丹以及存仓逻辑，消除非法空载荷包导致的网关掉线隐患。

### 3. 日常流水线避让熔断急停 (Evade Circuit Breaker)
- 在日常任务流水线（`_run_pipeline`）的原子子任务调度循环中，增加前置避让状态守卫：
  - 每个日常子任务（如 `take_bible`, `hero_mission`, `arena` 等）执行前，检查当前账号的 `evade_state`；
  - 一旦检测到账号已进入 `evading` 状态，立即熔断终止后续所有子任务调度，并安全释放所有连接，达成真正服从玩家微端优先的最高优先级原则。

## 影响与收益
- **彻底杜绝误避让与误掉线**：消除因非法数据包格式导致的网关强杀，避免普通网络波动将账号锁定在避让状态；
- **全链路避让一致性**：日常任务流水线与长连接会话状态深度联动，玩家顶号时后台全面急停让位，保障微端玩家体验顺滑不互踢。
