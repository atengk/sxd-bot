# ADR 0025: 智能滚动吸附与日志视窗动态展开架构

- **状态**: Accepted
- **日期**: 2026-10-17
- **作者**: Ateng

## 背景与问题陈述 (Context)

在神仙道 Web 控制台中，日志视窗此前在每次接收到后端 SSE 推流事件并调用 `appendLog` 时，无条件强制执行：
```javascript
consoleRef.value.scrollTop = consoleRef.value.scrollHeight;
```
当玩家或开发者在控制台中向上滚动鼠标滚轮翻阅排查历史日志时，常驻保活与子任务执行产生的新日志会瞬间打断用户的阅读视线并将滚动条暴力拉到底部。此外，日志缓冲区上限为 500 条且在视窗固定高度 `h-56` (224px) 下视野受限，在频繁日志流下顶部快速 `shift` 容易引起视窗跳动，深度排障体验不佳。

## 决策方案 (Decision)

我们决定引入 **智能滚动吸附 (Smart Bottom Stick)** 与 **视窗动态展开 (Console Expansion)** 机制：

1. **智能滚动吸附状态机 (Smart Bottom Stick)**：
   - 监听日志容器的 `scroll` 事件，计算当前视口距离底部的差值：`isAtBottom = (scrollHeight - scrollTop - clientHeight) <= 50`。
   - **吸附状态（默认）**：当用户停留在底部附近（差值 ≤ 50px）时，新日志到达平滑自动滚屏到底部。
   - **脱附锁定状态**：当用户向上滑动超过 50px 时，自动判定为“主动查阅历史”，解除自动滚屏，冻结视口位置，绝不自动下拉。
   - **悬浮直达胶囊**：在脱附状态下，视窗右下角动态浮现轻量交互胶囊【⬇ 有新日志 / 直达最新】，点击即可平滑滑回底部并重新激活自动吸附；若用户手动滚回底部，胶囊自动隐去并恢复吸附。
2. **翻阅时缓冲区保护 (Buffer Shifting Defense)**：
   - 将日志最大容量从 500 提升至 1000 条。
   - 当用户处于向上翻阅（脱附）状态时，延迟头部的激进 `shift()` 裁剪，待用户回到底部时平滑收缩，避免视窗内容因顶部削减发生抖动。
3. **日志视窗动态展开模式 (Console Expansion)**：
   - 工具栏右侧新增【最大化/还原】图标按钮，响应式控制容器高度在紧凑模式 (`h-56`) 与展开模式 (`h-[32rem]` / 512px) 之间无缝切换。

## 影响与收益 (Consequences)

- **积极收益**：
  - 彻底解决向上翻阅日志时被高频推流强行拉到底部的干扰问题。
  - 用户既能静默阅读历史，又能通过右下角胶囊直观感知是否有新日志产生并一键直达。
  - 扩大缓冲区并支持视窗高度动态展开，显著提升运维排障与日常观测体验。
- **潜在代价**：
  - 前端增加轻量滚动监听函数，需节流或基于 `requestAnimationFrame` 保证高频滚动时的流畅度。
