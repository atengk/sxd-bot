# 0008. 二阶段高产出日常资源流逆向与安全流水线设计 (Sprint 2 High-Yield Routine Pipeline)

- **状态**: Accepted
- **日期**: 2026-10-16
- **作者**: Ateng

## 1. 上下文与挑战 (Context & Problem)

神仙道日常运转体系中，高产出日常资源流（仙府药园、吉星高照、齐天大圣摘仙桃、喜从天降与通商）是角色获取海量升级经验、境界点突破材料、铜钱与代币的核心通道。
在逆向与工程落地过程中面临以下挑战：
1. **服务端体系演进**：微端新版服务端已全量升级为新版药园体系（`Mod 13, Act 21-26`），老旧 `Act 0/6` 接口仅存残留视图；偷桃核心模块位于 `Mod 40` (`Mod_GetPeach_Base`)，老旧的 `Mod 100` 或 `Mod 35` 仅为兼容或辅助调用。
2. **状态机严格与防断连机制**：神仙道网关对未处于特定 UI 状态或非活动状态的强行调用会下发 EOF 断开连接；在吉星高照已托管开启（`is_auto == 1`）时，若客户端非法注入手动投掷（`Mod 38, Act 0`）将直接触发连接切断。
3. **零元宝安全红线**：吉星改命（`Mod 38, Act 3`）、买猴子（`Mod 40, Act 2` 单次 50 元宝）、药园元宝催熟与购买种子均涉及元宝消耗，必须实施严格的物理级与逻辑级前置熔断。

## 2. 决策内容 (Decision)

我们基于微端 SWF 真实字节码反编译与实机流量抓包，构建了标准化高产出日常流水线：

1. **新版仙府药园体系 (`Mod 13`)**：
   - 使用 `Mod 13, Act 21` 获取 19 字节定长已开垦土地元数据，精准区分空地（`herbs_id == 0`）、生长期与成熟期（`farmland_time <= 0`）；
   - 对成熟土地调用 `Mod 13, Act 25` 进行单倍安全收获（绝不双倍）；
   - 对空闲土地自动调用 `Mod 13, Act 24` 播种 169 经验草或 175 铜钱草；
   - 自动探测（`Act 19`）并领取每日仙令礼包（`Act 20`）。

2. **吉星高照安全流与自动托管兼容 (`Mod 38`)**：
   - 使用 `Mod 38, Act 2` 解包剩余免费投掷次数与累计境界点；
   - 查询 `Mod 38, Act 6` (`is_auto`)：若已开启自动托管，仅领奖入库（`Act 4`）与状态同步，绝不重复发送手动投掷 `Act 0`，消除断连风险；
   - 强前置安全卫语句：若 `free_times <= 0` 立即 `SKIPPED`，物理阻断 `Act 3` 改命。

3. **齐天大圣一键批量偷桃 (`Mod 40`)**：
   - 使用 `Mod 40, Act 3` 和 `Act 4` 同步仙桃成熟度与层级概况；
   - 调用 `Mod 40, Act 5` (`batch_get_peach`) 执行一键批量摘取，单次结算海量角色升级经验；
   - 严格物理排除 `Mod 40, Act 2` (`buy_monkeys`)，杜绝元宝消耗。

4. **喜从天降与通商自动化 (`Mod 41`)**：
   - 调用 `Mod 41, Act 0` (`get_panel_info`) 完整获取 239 字节港口行情与资产代币；
   - 调用 `Mod 41, Act 2`、`Act 4`、`Act 5` 同步日常代币、最新行情涨跌指数与赛季时效。

## 3. 产生的影响与收益 (Consequences)

- **正向收益**：
  - 角色单日日常收益实现跨越式提升：一次性摘取高阶仙桃获得数十亿经验，药园稳定收割仙草，吉星高照境界点自动入库，通商资产行情实时同步；
  - 100% 保持网络长连接健康与零断连（`零断连` 指标实测验证通过）；
  - 全流程严守零元宝消耗安全底线。
- **关联测试与规约**：
  - 编写 `tests/test_sprint2_routine.py`，全套 6 项专业单测覆盖土地解包、单倍收获、自动播种、偷桃领奖与通商同步；
  - 全工程 24 项单测保持 100% 通过。
