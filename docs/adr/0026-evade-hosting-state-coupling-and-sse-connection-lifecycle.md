# 26. 避让托管状态机关联、孤儿套接字绝对熔断与 SSE 连接生命周期实时驱动决策

## 状态
已接受 (Accepted) - 2026-10-17

## 背景与问题陈述
在 Web 控制台与真机自动化联调过程中，发现了以下两项影响操作确定性与视觉体验的关键缺陷：
1. **全员避让时托管开关未关闭且偶发微端登录受阻**：
   - 避让逻辑此前仅标记了 `evade_state = 'evading'`，未改动 `hosting_enabled`（仍为 `True`），导致前端卡片【长连接托管】复选框保持高亮开启，产生“避让未生效”的直观困惑；
   - 在常驻守护协程中，若避让信号到达时协程正处于凭据换取或 `connect()` 握手期，尚未完成 `_sessions[alias]["client"]` 登记，协程 `cancel()` 后缺失 `finally` 兜底清理，导致底层孤儿 TCP Socket 悬挂在操作系统协议栈中，游戏网关仍判定角色在线，微端无法登录。
2. **全员恢复后卡片永久停留在【离线 / 未连接】**：
   - 全员恢复异步拉起后台长连接协程，鉴权握手需要 1~2 秒；但前端在 API 返回瞬间（几毫秒内）立即执行 `loadAccounts()`，此时物理连接未就绪，返回了 `connection_status: "disconnected"`；
   - 随后底层在后台握手成功并接入长连接后，仅更新了私有变量而从未向外部广播连接建立事件；且由于已废除全页暴力定时刷新（以防页面白屏闪烁），导致前端 Vue 响应式状态永久停留在离线状态。

## 决策内容

### 1. 避让与长连接托管状态机关联 (Evade-Hosting State Coupling)
- **避让时自动关停托管**：全员避让 (`evade_all`) 或单号避让 (`trigger_evade`) 触发时，同步将数据库持久层 `hosting_enabled` 置为 `False`，并强杀物理 TCP 连接；前端卡片【长连接托管】开关即刻联动关闭，界面行为与底层物理状态保持高度一致。
- **恢复时自动重置并开启**：全员恢复 (`resume_all`) 或单号恢复 (`resume_hosting`) 触发时，自动清除避让标记并重置 `hosting_enabled = True`，重新拉起后台长连接守护。

### 2. 强杀式避让底层 Socket 的生命周期自愈保护 (Orphan Socket Zero Tolerance)
- **创建即时登记**：在 `_hosting_worker` 协程中，一旦实例化 `SXDClient`，立即登记至全局会话表中，确保任何瞬态被避让拦截时均可被 `abort()` 准确定位。
- **全生命周期 `finally` 熔断**：为常驻协程加装严格的 `try ... finally` 闭环。无论协程是在休眠、网络握手还是收发包期间被 Cancel，`finally` 块确保未关闭的套接字一律 100% 同步执行 `abort()` 发送 TCP RST，彻底消灭孤儿长连接。

### 3. SSE 驱动的连接生命周期状态机与过渡态呈现 (SSE Connection Lifecycle & Transient State)
- **过渡态引入**：引入 `connecting`（正在连入网关...）瞬态。全员恢复触发瞬间，卡片状态胶囊立即展示脉冲过渡态，消除网络握手时延导致的脱节感知。
- **实时事件广播**：
  - 底层 Socket 完成网关握手与登录认证后，通过 EventBus 广播 `ACCOUNT_CONNECTED`，携带别名与角色基础信息；
  - 连接非正常断开或主动避让强杀时，广播 `ACCOUNT_DISCONNECTED`；
  - 触发避让时，广播 `ACCOUNT_EVADED`。
- **前端零闪烁原位自愈**：前端 `EventSource` 监听上述连接生命周期事件，就地无感更新目标卡片的 `connection_status` 与 `hosting_enabled`，彻底达成零轮询、零白屏闪烁的平滑体验。

## 影响评估
- **积极影响**：
  - 全员避让 100% 杜绝悬挂连接，微端登录秒让位，操作开关视觉联动明确；
  - 全员恢复状态秒级响应，过渡态与在线态平滑切换，运维可观测性大幅提升；
  - 彻底杜绝全页频繁重载与闪烁。
- **向后兼容性**：
  - 完全兼容既有 SQLite 配置表结构与 REST API 响应模型。
