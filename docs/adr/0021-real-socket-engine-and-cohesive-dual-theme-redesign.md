# 0021. 真机Socket网络托管引擎接管与明暗双模调色盘重构

- **状态**: Accepted
- **日期**: 2026-10-16
- **决策者**: Ateng
- **关联 Issue/PR**: Web 控制台视觉重塑与真机日常流水线接入

---

## 背景与问题陈述 (Context)

在既有 Web 控制台（`web/static/index.html` 与 `web/session_manager.py`）运行过程中，暴露了两个严重影响可用性与用户体验的核心缺陷：
1. **假数据与假自动化流水线**：
   原 Web 控制台底层 `session_manager.py` 内部日常执行采用虚拟的 `await asyncio.sleep(0.02)` 打印模拟日志，并未建立真实的 `SXDClient` TCP Socket 长连接发包，导致所有账号在 Web 界面呈现的资产均为 0（铜钱 0、元宝 0、声望 0、假体力 150/200），日常福利功能形同虚设。
2. **界面视觉与色彩搭配严重翻车**：
   原界面在 Tailwind CDN 运行时配置下因 darkMode 识别失效，导致暗黑模式下页面背景为深黑（`#090d16`）而卡片强制回退为惨白（`bg-white`），产生“黑底死白大方块”的恶性视觉冲突；同时浅色模式下对比度过低、顶栏操作按钮在标准分辨率下发生右侧溢出截断，下部日志视窗与整体色调割裂严重。

---

## 架构决策 (Decision)

我们决定对 Web 会话调度内核与单页前端进行双重彻底重构：

### 1. 真实 Socket 长连接托管引擎接管
- 在 `web/session_manager.py` 中彻底移除任何 `sleep` 模拟桩，引入真实的 35 项日常任务构建字典（`ROUTINE_TASK_BUILDERS`）。
- **长连接托管协程 (`_hosting_worker`)**：
  为启用托管的账号建立真正的常驻 `SXDClient` TCP 套接字通道，监听协议顶号通知包（Mod 100 Act 22 与 Mod 0 Act 15）自动触发避让，并以 15 秒周期持续发送心跳包保活。
- **真机日常流水线调度 (`_run_pipeline`)**：
  优先复用当前活跃的托管 Socket 连接（无活跃连接时创建短时无头客户端），执行真实游戏网关登录与全套已启用的日常福利任务。
- **全景态势即查即存与实时刷报**：
  日常流水线收官后，自动调用 `QueryService.query_all()` 实时拉取角色资产、伙伴阵容与背包快照并写入 SQLite 角色数据库；同时提供 `POST /api/accounts/{alias}/telemetry/sync` 按需抓取端点，并通过 SSE 发布 `telemetry_updated` 事件，驱动前端资产数字毫秒级自动刷新。

### 2. 自研可靠 CSS 变量双模设计系统
- 废除脆弱且易受 CDN 覆盖的 Tailwind 动态 `dark:` 类名，采用统一的 CSS 自定义属性（`--bg-page`, `--bg-card`, `--bg-card-sub`, `--border-card`, `--text-primary`, `--terminal-bg` 等）。
- **暗黑极客模式 (`html.dark`)**：
  背景采用深空暗蓝黑（`#0b0f19`），卡片采用高质感深灰蓝（`#111827`）与微差子区域（`#0e1626`），配合高清晰皓月白字（`#f8fafc`）与柔和蓝紫琥珀色点缀，彻底消灭黑底死白卡片。
- **明亮白昼模式 (`:root`)**：
  背景采用柔和浅灰（`#f1f5f9`），卡片采用纯净白（`#ffffff`）与微弱阴影（`rgba(0, 0, 0, 0.05)`），文字采用高对比深墨黑（`#0f172a`）。
- **全黑极客终端视窗**：
  在明暗两种主题下，日志控制台统一保持全黑终端风格（`#070a12`），配备鲜明的彩色语法高亮（绿色成功、琥珀避让警告、红色错误、天蓝调度）。
- **防截断弹性布局**：
  顶部导航栏改用 `flex-wrap` 与 `gap-2` 弹性流动排列，彻底消除任何屏幕宽度下的操作按钮溢出与右边界截断问题。

## 影响与收益 (Consequences)

### 正向收益 (Pros)
1. **真实可信**：Web 控制台下发日常全部由真实游戏 Socket 驱动，数据即查即存，资产卡片真实反映玩家当前财富与进度。
2. **视觉优雅**：无论用户操作系统处于何种默认模式或 CDN 网络状况，明暗双模均实现 100% 可靠着色，科技感与舒适度大幅提升。
3. **架构闭环**：继续保持前后端不分离极简交付，零 Node.js / Webpack 编译依赖，全量 196 个单元测试 100% 绿色通过。

### 潜在风险与缓解 (Cons & Mitigations)
- **并发套接字竞争**：若用户在长连接托管中手动快速连击“单跑日常”，可能产生网络发包交织。
  - *缓解措施*：为每个账号引入独占 `asyncio.Lock`，保障心跳保活与流水线任务串行安全。
