# 协议全域真理源归一化与业务模块动作矩阵重构

由于历史逆向推演与抓包分析中存在部分接口标注偏差，导致 `mod_action_matrix.md` 及部分业务任务代码中出现模块编号错位与串线（如将帮派祭神错标为 Mod 21、猎命与通商错标为 Mod 41、招财错标为 Mod 76、签到错标为 Mod 42/127 等）。我们决定确立官方逆向字典库 `protocol_manifest.db`（对应 `02_protocol_index_catalog.md`）为项目全局唯一真理之源（Single Source of Truth），全面修正所有文档、任务逻辑和单元测试，确保自动化协议封包 100% 对齐官方 ActionScript 二进制规范。

## 状态
Accepted

## 考虑的选项
- **选项 1：保持既有代码不变，仅在文档中做兼容注解**：成本低，但代码向游戏服务端发送错误协议号必将被网关判定异常而掐断 TCP 长连接，系统无法在实机环境中正常工作。
- **选项 2：全面依照 `protocol_manifest.db` 归一化重构（采纳）**：严格以反编译提取的 880 个模块与 8,719 个动作定义为基准，消除代码中的伪指令与伪 Hex，补齐空桩任务，使端到端协议与单测完全闭环真实。

## 影响与后果
- 所有任务的模块号与动作号均与官方微端真实客户端一致，杜绝服务端报错掐线风险；
- 单元测试重构为验证真实的协议编号与载荷类型，避免虚假通过；
- 技术文档 `mod_action_matrix.md` 恢复为权威准确的开发参考手册。
