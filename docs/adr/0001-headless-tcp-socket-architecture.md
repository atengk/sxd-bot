# 0001 无头原生 TCP 长连接架构

传统的页游挂机自动化往往依赖微端内嵌浏览器注入或 Flash 容器内存 Hook，导致极高的系统资源开销（单开内存 > 500MB）与极差的跨平台稳定性；本项目决定完全剔除图形化 UI 容器，基于逆向还原的 Flash ByteArray 二进制通信协议，使用 Python `asyncio` 原生构建无头异步 TCP 长连接客户端；该架构将常驻运行内存压缩至 30MB 以下，同时保障了微秒级的指令吞吐与高并发挂机稳定性。

## Status

accepted

## Considered Options

- **选项 1：无头原生 TCP Socket 长连接通信（采纳）**：完全基于逆向协议编解码，零 GUI 开销，内存开销 < 30MB，支持高并发与轻量 Linux/云主机无界面常驻。
- **选项 2：Playwright / Selenium 浏览器无头仿真**：依赖微端 Flash 插件或 Chromium 渲染 DOM，内存开销巨大（300MB~1GB），且无法绕过网页 Flash 播放器在现代浏览器的淘汰限制。
- **选项 3：Windows 桌面微端进程注入与内存 Hook**：强绑定 Windows 操作系统与特定微端版本，极易因微端壳更新失效，且难以容器化部署。

## Consequences

- 运行开销大幅下降，单机支持数百实例后台并发运行；
- 摆脱对任何 Flash Player 运行时与图形界面的依赖；
- 必须承担逆向维护二进制协议变动的成本，要求网络层对封包字段长度与结构高度严谨。
