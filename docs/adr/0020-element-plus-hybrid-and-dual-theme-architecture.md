# 0020. Element Plus 混合架构、明暗双模主题与高质感游戏资产渲染规范

- **状态**: Accepted
- **日期**: 2026-10-16
- **作者**: Ateng

## 背景与上下文

在神仙道 Web 控制台接入 Vue 3 响应式运行时后，界面视觉与操作体验迎来进一步升级诉求：
1. **视觉专业度与交互反馈**：原有浏览器原生 `alert()` 与基础 HTML 表单反馈单薄，缺乏现代企业级/游戏级 Web 应用应有的轻量消息提示 (Toast Notification)、优雅过渡动效与高级交互控件；
2. **多场景光照与环境自适应**：用户明确提出“加个切换黑白色”（深浅色模式切换），以满足夜间常驻运维（深色沉浸、防刺眼）与白天办公场所（浅色清爽、防窥探）的无缝切换诉求；
3. **架构约束不变量**：必须 100% 恪守“前后端不分离、单文件极简静态托管、零 Node.js 编译工具链”的技术底线。

## 架构决策

1. **Element Plus + Tailwind CSS 混合架构 (Hybrid UI Paradigm)**:
   - 通过 CDN 全局引入 Element Plus (`index.css` + `index.full.min.js`) 并注入 Vue 3 实例；
   - 复杂交互与全局反馈由 Element Plus 接管（如 `ElNotification` 浮动通知、`el-switch` 丝滑开关、`el-tooltip` 浮标气泡）；
   - 页面宏观网格系统、自适应流式排版与游戏粒子质感仍由 Tailwind CSS 统一编排，优势互补。

2. **明暗双模主题系统 (Dual-Mode Theme)**:
   - 在 `<html>` 根节点上纳管 `class="dark"` 状态，配合 CSS Variables 与 Tailwind `darkMode: 'class'` 实现全景变量级双模支持；
   - 引入暗黑模式专用变量库 (`element-plus/theme-chalk/dark/css-vars.css`)，确保组件库与定制卡片视觉色调完全同步；
   - 状态持久化于浏览器的 `localStorage.getItem('sxd_theme')`，并在 `<head>` 顶部注入防白屏闪烁（Anti-FOUC）轻量脚本；
   - 顶部导航栏右侧常驻明暗模式切换按钮（☀️ 浅色白昼 / 🌙 暗黑极客）。

3. **游戏品质光泽强化 (Game Asset Quality Elevation)**:
   - 对 100 格背包道具快照依据品质实施视觉升维：
     - 金色品质：琥珀金光晕与渐变发光阴影 (`shadow-[0_0_10px_rgba(245,158,11,0.25)]`)；
     - 紫色品质：暗夜紫光晕与深邃发光边框；
     - 蓝色品质：深海天蓝微光与高亮品质角标；
   - 账号卡片在“防互踢避让”时触发呼吸渐变金色边框，在“托管在线”时展示翡翠绿脉冲光环；
   - 弹窗与抽屉全面适配双模底色与磨砂玻璃高斯模糊（`backdrop-blur`）。

## 方案权衡与影响 (Consequences)

- **正面收益**:
  - 彻底告别粗暴的浏览器原生 `alert`，操作反馈体验跃升为现代化 Web 应用水准；
  - 完美兼顾夜间挂机沉浸感与日间办公清爽防窥，提升可用性；
  - 100 格背包道具品质层次分明，游戏资产快照质感逼近端游原生体验；
  - 维持前后端不分离与极简 Docker 部署体验不变。
- **代价与权衡**:
  - 前端增加了 Element Plus 静态 CDN 资源依赖（已配置稳定 jsDelivr 全球加速，并保留容错降级逻辑）。
