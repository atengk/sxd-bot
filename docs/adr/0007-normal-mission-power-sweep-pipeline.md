# 0007 普通副本极速扫荡与体力生命周期管理流水线

神仙道角色体力随时间自然恢复（上限通常为 200 点），若不及时消耗会导致体力溢出浪费，而常规手动挂机或普通扫荡存在漫长的排队倒计时（每场数秒至数十秒）且极易因海量战斗掉落导致主背包爆仓；本项目决定基于微端逆向确认的 Module 25（`Mod_MissionPractice_Base`）协议，设计“状态解除 ➔ 批量启动 ➔ 极速秒加速”的三步原子扫荡流水线，并在发包中硬编码开启低级杂物自动回收（`AutoSale=1`），在 `--once` 单次模式与 `--daemon` 守护模式（默认 30 分钟周期巡检）中动态按 `体力 // 5` 计算最大轮数快速清空体力；该决策实现了秒级清空体力与战报结算，彻底防止了体力自然溢出与背包爆仓。

## Status

accepted

## Considered Options

- **选项 1：Module 25 极速秒加速 + 零元宝硬防御 + 自动回收杂物（采纳）**：在发送 `Mod 25, Act 1` 启动扫荡后立即发送 `Mod 25, Act 3` 触发免费极速秒加速，耗时由数十分钟压缩至数百毫秒，且通过参数强制开启杂物变卖，完全规避元宝消耗。
- **选项 2：客户端异步协程等待倒计时自然结束**：每场战斗等待 5~30 秒，消耗 200 点体力需要挂机 10~20 分钟，网络波动风险极高且极大拖慢自动化流水线。
- **选项 3：盲目调用 Module 35 章节扫荡接口**：微端协议逆向证实，在非章节城镇地图盲目发送 Module 35 扫荡包会导致网关判定报文序列非法并主动下发 RST/FIN 切断连接（EOF）。

## Consequences

- 角色体力利用率达到 100%，杜绝了 24 小时挂机模式下的体力浪费；
- 掉落的低阶白装杂物自动折现为铜钱，保护背包高价值材料不被挤出；
- 需在 `GameContext` 中实时感知与维护角色的当前体力属性（`Mod 0, Act 3` 属性变更广播）。
