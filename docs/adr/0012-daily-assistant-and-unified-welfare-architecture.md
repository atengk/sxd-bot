# 0012 小助手、仙道问灵、点金石与全服福利收割架构

本项目在已完成基础日常、家园药园、仙履奇缘与副本扫荡的基础上，进一步接入神仙道高阶日常体系，涵盖小助手（Mod 52）、仙道问灵（Mod 503）、点金石（Mod 551）、周末狂欢（Mod 637/638）、系统邮件与更新补偿（Mod 345）以及城镇练功打坐（Mod 45）。为保障长连接稳定性与零元宝消耗安全底线，制定本架构设计。

## Status

accepted

## Context

随着玩家角色等级达到 300 级，游戏内大量高阶日常与集成辅助面板全面开放。这些功能具有以下特点：
1. **活跃度后置强相关**：小助手宝箱依赖于全天日常操作累积的活跃度，提前领取会导致高档位宝箱遗漏；
2. **时段敏感性强**：周末狂欢仅在周六与周日开放，工作日请求会触发网关无效报文防御；
3. **高频附件收割与防爆箱**：版本更新补偿与停服维护大礼包均通过系统邮件发放，不及时清理空邮件会导致上限爆满而丢包；
4. **自选资产防误触**：仙道问灵签文兑换涉及高价值自选核心资源（如神器、命宫、轮回石），不可盲目代玩家自选兑换。

## Considered Options

- **选项 1：独立高内聚业务任务 + 调度器前置/后置双时序编排 (采纳)**：
  - **小助手 (Mod 52: Assistant)**：前置查询日常与系统未完成项状态；后置在所有战斗与日常结束后一键领取全部已解锁活跃度宝箱（`one_key_get_award`）。
  - **仙道问灵 (Mod 503: AskFairy)**：每日执行 1 次免费问灵（`do_ask_fairy`），自动领取签文奖励；兑换商店保留由玩家在端内自选。
  - **点金石 (Mod 551: GoldenTouchStone)**：自动执行每日全部免费点金次数（`touch_stone`），并遍历好友求助列表无损协助（`help_friend`）。
  - **周末狂欢 (Mod 637/638: WeekendRevelry)**：本地引入 `weekday in (5, 6)` 严格时段守卫，仅周末自动领全套免费礼包与开启免费委托。
  - **系统邮件 (Mod 345: Email)**：执行原生一键提取所有邮件附件（`one_key_get_award`），并清理无附件的过期系统通告。
  - **城镇练功 (Mod 45: Practice)**：流水线收官时指令角色进入打坐挂机状态，保障离线经验收益。
- **选项 2：将所有福利合并为单一巨型脚本**：
  - 破坏了现有 `BaseTask` 的插件化拆分规范，异常无法精细隔离，排查与单测成本极高。
- **选项 3：全盘自动兑换仙道问灵商店**：
  - 破坏了“零破坏性变更与防御性决策”规范，极易误消耗玩家辛辛苦苦积攒的稀有签文兑换非目标神器。

## Consequences

- **收益最大化**：小助手在全套日常产出活跃度达到峰值时一键结算，全额吃透所有阶梯宝箱；
- **零误触防线**：仙道问灵只做日常免费求签，坚决不代做自选道具决策；
- **时段精准防御**：周末狂欢自动识别星期几，周一至周五零网络冗余包，杜绝网关防刷断连；
- **邮箱永不爆满**：停服与版本更新大礼包自动落袋，无用废信自动清理。
