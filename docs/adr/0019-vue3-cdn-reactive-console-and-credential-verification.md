# 0019. Vue 3 CDN 响应式单体控制台、凭据强校验与心动官服鉴权架构

- **状态**: Accepted
- **日期**: 2026-10-16
- **作者**: Ateng

## 背景与上下文

在多账号 Web 控制台投入实际使用过程中，面临以下工程痛点与架构需求：
1. **前后端架构约束**：用户明确要求“上现代前端框架，但前后端不分离”，杜绝引入繁重的 Node.js、Webpack 或 Vite 构建管线与双进程运维负担；
2. **账号录入容错与防误录**：原有控制台录入账号无前置连通性校验，若账号密码或区服填错，将导致后台长连接持续报错重试，污染日志与连接池；
3. **多平台生态扩展**：根据最新抓包分析，心动官方微端 (`xd.com`) 与联运渠道服（如烽玩 `fengwanyx`）在 Web 鉴权、入场票据生成与大区网关换取机制上存在差异，亟待纳管心动官服鉴权提供方；
4. **前端性能与数据生命周期**：手动 DOM 拼接难以维护动态卡片矩阵、100 格背包道具快照与 35 项独立配置，亟需现代化响应式数据模型与按需懒加载机制。

## 架构决策

1. **Vue 3 全局 CDN 运行时单体架构 (Vue 3 Production Drop-in)**:
   - 控制台前端直接在 `index.html` 中引入 `vue.global.prod.js`，采用声明式响应式驱动全量视图与操作；
   - 彻底废弃手动 DOM 字符串拼接与直接 DOM 操作，所有账号卡片、指标徽章、抽屉选项卡与日志终端均由 Vue 3 响应式状态 (`reactive`, `ref`, `computed`) 统一驱动；
   - 维持前后端不分离体系，纯静态单文件依然由 FastAPI 统一挂载托管，零 Node.js 编译工具链，开箱即用。

2. **前置强校验与测试登录卡点 (Test Login / Credential Verification)**:
   - 后端新增 `POST /api/accounts/test-login` 探测端点，接收账号凭据并在内存沙箱中调度对应平台的 `auto_login` 进行真实票据校验与网关换取；
   - 前端弹窗提供【测试登录】动作，测试成功后自动拉取并回填角色昵称与网关信息；
   - 点击【保存】时实施强卡点拦截：若此前未显式测试或凭据发生变动，自动执行前置静默校验，仅当测试完全通过后方可持久化写入 SQLite。

3. **心动官服鉴权提供方 (`XDPlatformAuthProvider`)**:
   - 新建 `network/platforms/xd.py` 并注册至 `PlatformAuthRegistry`；
   - 严格遵循微端抓包全生命周期：
     1. 请求 `https://www.xd.com/users/loginService` 完成账号密码鉴权并沉淀 Session Cookie；
     2. 请求 `https://www.xd.com/games/play` 换取目标区服入场票据；
     3. 请求目标大区 `index_wd.php` 获取长连接 Hash Token 与网关 IP/Port；
   - 前端录入弹窗提供平台枚举切换，针对心动官服展示定制化区服提示（如 `S3542`）。

4. **分级按需遥测 (Lazy Telemetry)**:
   - 主界面卡片矩阵仅绑定账号列表与基础在线/避让状态；
   - 100 格背包道具快照、小助手活跃度与 35 项日常独立配置仅在用户点击卡片展开详情抽屉时按需拉取，杜绝大量账号时的首屏请求风暴。

## 方案权衡与影响 (Consequences)

- **正面收益**:
  - 代码可维护性成倍提升，响应式单向数据流杜绝 DOM 渲染状态不一致；
  - 100% 杜绝因手滑输错密码或区服导致的废账号入库问题；
  - 完整覆盖官方微端与联运渠道，多平台扩展路径清晰规范；
  - 坚持单体极简交付，维持 Docker/单机直接 `python main.py web` 极简部署体验。
- **代价与权衡**:
  - 前端依赖外部 CDN 资源加速（可通过本地静态托管降级）；
  - 新增账号时必须具备外网网络连通性以执行前置测试登录。
